# CropSmart Research Digital Twin

A standard React + Vite + TypeScript materialization of the CropSmart agricultural water–energy intelligence research demonstration.

## Run from the project root

```bash
npm install
npm run dev
npm run build
```

The application uses deterministic synthetic observations and modeled outputs. It preserves the Cedar Creek Research Farm, OPEN-A, AV-A, AV-B, EXPERIMENTAL-A, run identities, provenance labels, scenario controls, 72-hour predictions, uncertainty exploration, resource allocation, and research export workflows.

No database persistence is fabricated in this release. The existing Blink database schema remains external to this static demonstration.
