# Published FAO-56 benchmark — Chapter 4 Example 17

Primary source: Allen, Pereira, Raes & Smith (1998), FAO Irrigation
and Drainage Paper 56, Chapter 4, Example 17, Bangkok April.
https://www.fao.org/4/X0490E/x0490e08.htm

Published rounded intermediate values:
Delta 0.246 kPa/C; gamma 0.0674 kPa/C; Tmean 30.2 C;
u2 2 m/s; es 4.42 kPa; ea 2.85 kPa;
Rn 14.33 MJ/m2/day; G 0.14 MJ/m2/day.

Published reference ET0: 5.72 mm/day (5.7 rounded).
Calculated from the printed intermediate values using Eq. 6:
approximately 5.71338 mm/day; tolerance 0.03 mm/day.

The discrepancy is compatible with rounding of intermediate values.
This is a **published numerical reference-ET benchmark**.
It is NOT a published worked example for the complete dual-Kc surface
evaporation/root-zone coupled model; those remain unverified against a
published numerical example.

Verification requires running the new unittest on the latest commit,
archiving test log, source SHA, dependency versions and artifact checksum.
