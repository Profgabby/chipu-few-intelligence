# Scientific model boundaries

CHIPU-FEW Resilience 0.1.0 is a transparent composite decision indicator derived from the existing scenario/control outputs. It must not be described as independently validated field resilience. CHIPU-FEW Economics 0.1.0 is an assumption-driven cash-flow calculator; it must not be described as a financial forecast or investment recommendation. People and Place persist documented context but do not infer stakeholder behavior, adoption, soil properties, hazards, or infrastructure when those records are absent.
