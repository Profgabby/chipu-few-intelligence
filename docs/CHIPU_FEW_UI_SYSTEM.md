# CHIPU-FEW Interface System

The interface intentionally avoids a generic SaaS dashboard aesthetic. Core domain pages use a systems-cockpit composition: deep FEW-green editorial hero, restrained scientific surfaces, context/evidence ledgers, continuity bands, assumption-first analysis panels, explicit provenance states, and empty states instead of invented KPI values.

Design rules: preserve dense research information without visual clutter; use hierarchy rather than decorative cards; reserve status colors for meaning; show evidence/source labels adjacent to records; never populate production metrics with demo values; keep mobile layouts single-column and readable; preserve existing scientific workspaces rather than restyling their computational content into marketing widgets.
