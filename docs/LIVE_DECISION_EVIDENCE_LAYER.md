# CHIPU-FEW Live Cross-Module Decision Layer

The live decision layer is an evidence-lineage view over the existing CHIPU-FEW modules. It does not introduce new scientific claims or duplicate scientific engines.

## Directed architecture

People + Place → Food ↔ Energy ↔ Water → Twin → Predict → Control → Economics + Resilience → Decision Support

## Design rules

- Node state is derived from evidence that actually exists in the selected Research Workspace → Farm/Site → Zone → Scenario context.
- Missing evidence remains explicit. The graph never fills a missing module with demo KPI values.
- Existing synthetic research records remain visible as synthetic/context evidence rather than being presented as measured production evidence.
- Edge state expresses whether the evidence dependency is currently supported, partial, protected, or blocked.
- Clicking a node opens a lineage inspector showing the source, current signal, downstream role, and next action.
- Existing scientific engines remain the source of Twin, Forecast/Predict and Scenario/Control evidence.
- Persistent People, Place, Resilience and Economics evidence continues to come through the protected server persistence layer.
- The graph is a coordination and provenance layer; it is not itself a predictive or optimization model.
